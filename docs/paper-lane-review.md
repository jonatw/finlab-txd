## 2026-07-17 — 月度 review:paper lane vs 回測大幅偏離(verdict: **TAIL-BUT-IN-MODEL / 黃旗掛起**)

**起因**:paper-lane 滿 20 個交易日(6/17–7/16),live NAV 0.8932 = **−10.68%**,而回測多年
數字漂亮,使用者問「為什麼差這麼多,是極端行情嗎」。逐層排除後定性。

**1. 不是 bug**:TWSE 交叉驗證乾淨(`xcheck.json` mismatch=false);逐日 PnL = 生效曝險 ×
大盤報酬,分毫核對無誤(6/26 −3.64%×2=−7.28 ✓ / 6/30 +2.50%×2≈+4.96 ✓ / 7/7 −2.31%×2=−4.63 ✓);
訊號 T+1 時序正確。機器沒有壞。

**2. 大盤沒崩,死因是 gate 鞭打**:同窗加權指數僅 **−0.55%**(自身 DD −6.6%),2x 純被動對照
−1.63%。缺口 ~9pp 全來自三次「滿倉吃單日大跌 → 收盤關機 → 隔日空手看反彈」:

| 事件 | 吃到 | 隔日錯過 |
|---|---|---|
| 6/26 關機 | 2x × −3.64% = −7.28% | 6/29 +0.96% |
| 6/30 再觸發 | (當日有抓到 +4.96%) | 7/1 +1.94% |
| 7/7 關機 | 2x × −2.31% = −4.63% | 7/8 +0.56% |
| 7/14 關機(1x) | −1.44% | 7/15 **+1.99%** |

空手 4 天大盤**全漲**,合計 +5.46%(×2 ≈ **10.9pp 機會成本**);歷史空手日大盤平均 **−0.03%**
(n=469,gate 關機後通常續跌=它 2022/COVID 賺錢的原因)→ 這次 4 次擲硬幣全輸。
= documented 已知弱點(反應式煞車、防爆發日不防鞭打)被連打三次,非未知風險。

**3. 行情極端在 pattern 不在幅度**:
- 20 日內 DTP 觸發 **3 次** = 歷史 6,778 個交易日中僅 **0.7%** 的窗口出現過 ≥3 次(max 4)。
- live 20 日 −10.68% = 回測 27 年 20 日滾動分布的**第 1.3 百分位**(p5 −7.1%/p1 −11.4%/min −21.2%)
  → 尾部,但**在模型內**。
- 回測曲線自己在 **2025-11、2026-03 也各有一次 −10% 20日窗** = 高鞭打 regime 在 deploy 前就在,
  live 撞上第三發;且 6/17 是距 52 週高 −1.25% 處以 2x 進場(sequence risk 實現)。

**4. 黃旗(預先登記判準已觸及)**:live 低於 bootstrap p5 已 **9/20 天、最近連續 7 天**;
current DD **−21.85% 刷新 2016 後紀錄**(前 −20.0%;全史 −34.4% 在 1999-2008 段)。
6/26 review 寫的「持續貼 p5 下緣才是真衰退訊號、需月級樣本」——月級樣本到了,正式掛黃旗。
誠實邊界:單次 p5 突破仍是 5% 事件,檢力有限,「倒楣 vs 壞掉」還分不出來。

**5. 歷史 base rate(20 次 20日≤−10% 事件,去重疊)**:之後**不 cascade**(+120d 最慘 −9.5%),
但 +60d 中位 −3.8%、勝率 26% = 通常再橫盤陰跌一~兩季;+120d 平均 +11.6% 靠 2009/2025 型反彈(肥右尾)。

**6. 錨定校正**:全史 Sharpe **0.88**(CAGR 16.4%)才是正確期望;近 3 年 Sharpe 2.05 是大多頭段。
「跟回測差很多」有一半是拿 2023-25 曲線當錨。另 2x ≈ 滿凱利(μ/σ²≈2.3x)是知情選擇:
−20% 級回撤是設計內建,半凱利(1x)會把痛砍半——真錢部署計畫本來就是先 1x 爬坡。

**Verdict**:**TAIL-BUT-IN-MODEL。** 流程正確、機器無誤、結果在回測定價內(第 1.3 百分位籤);
真錢會遇到一模一樣的曲線(TX 流動性/夜盤/成本已建模),差異只在真錢多「人在谷底棄船」風險。
**不調門檻**(125-config CPCV 已證調參=過擬)。**預先登記下一步**:若到 ~7/27 review 仍持續
貼 p5 下緣 → 正確動作是**降槓桿或停錶,不是調參**——規則現在寫下,不在痛裡決定。

復現:`data/derived/curve.csv` + `site/data/health.json`;分析=20日滾動報酬百分位 + gate 觸發
頻率 rolling 窗 + 空手日大盤 base rate + 20 次歷史同級事件 forward 分布(本次 session 腳本)。

## 2026-06-26 — 首次深度回撤事件:正常性 review(verdict: **NORMAL / 在模型內**)

**起因**:部署第 7 個交易日,paper-lane 回撤達 all-time DD **−17.8%**(health `current_pct`)/ 自 6/17 起 **−14.4%**(期間報酬 −6.1%),逼近 2016+ MDD −20.0%,使用者擔心「快到歷史位置」。

**三個判斷(從回測 history)**

1. **幅度正常,非極端。** −17.8% 被 **29% 的歷史交易日**超過(更深);策略本來就常駐 −14%+ 回撤;離全期最深 −34.4% 還有一半。歷史 DD 中位 −12.3% / p25 −20.4% → 現在落在第 29 百分位 = 中等偏深但常見。
2. **幾乎全是 2x 槓桿,非策略壞掉。** 同窗大盤(加權指數)只跌 **−2.85%**(自身 DD −7.3%);~1.71x 平均曝險把它放大到 ~−12.5%(實際 −14.4%)。= 槓桿在回檔時該有的數學,不是 alpha 衰退。
3. **唯一不尋常是「速度」。** 7 日報酬 −6.1% 落在歷史 **最差 ~3%**;live NAV 跌破 bootstrap **p5 下緣**(day6 p5=0.9536 vs live 0.9394)。但 n=6–7 天近乎零檢力(health note 已聲明),快速回檔本來就會發生。

**深入研究「這種 case 多嗎 + 之後通常怎樣」(27 年, 6785 交易日)**

| 指標 | 數字 |
|---|---|
| 快速下跌(7日 ≤ −6%)頻率 | **194 次 / 27 年 ≈ 每年 7 次**(= 最差 3% tail) |
| 同樣但在 ≥1.5x 槓桿(對齊現在 2x) | **50 次 ≈ 每年 1.8 次**(gates 通常先降槓桿,故較少) |
| 觸發後 DTP 10 日內關機比例 | **65/194 = 34%**(煞車常會跟上) |

**觸發「7日≤−6%」後的 forward 報酬(含 DTP 關機反應)= 不會 cascade、平到回復:**

| forward | 中位 | 平均 | 勝率 | 最慘 |
|---|---|---|---|---|
| +5d | +0.0% | +0.6% | 38% | −9.3% |
| +10d | −0.0% | +0.8% | 40% | −13.0% |
| +20d | −0.3% | +1.4% | 47% | −11.3% |
| +40d | −1.9% | **+3.5%** | 40% | −12.2%(p90 **+20%**) |

→ 短期硬幣(略偏下,勝率 38–40%),但**下檔受限**(歷史最慘也只再給 ~−13%,從不失控);~40 日平均**回復 +3.5%**、上檔肥尾 p90 +20%。**快速回檔 ≠ −34% 崩盤的開始。**

**煞車狀態**:事件當下 DTP% 衝到 **98% > 96% 門檻 → 目標曝險歸 0(空手)**。= 高波動關機如設計般觸發,正在去風險。⚠️ 誠實註:DTP 是**反應式**煞車(波動衝高才觸發),沒**預防**這 −14%,只止血;這是已知設計(防爆發日、不防慢跌、反應偏晚)。

**Verdict**:**NORMAL。** 教科書式「槓桿回檔 → DTP 關機」,坐在回測分布的肉身段(現在 −17.8% = 第 29 百分位)。這個深度早已被回測 −34% max 定價進去。唯一回測無法保證的是「這一次會不會落在不幸的 tail」,但 base rate 說:猛、正常、通常會回復。**不需動作**(策略已自動關機到空手);續觀察 paper-lane 是否持續貼著 p5 下緣(那才是真衰退訊號,但需 ~月級樣本才有檢力)。
